# clinics-tools

- Each tool is its own `*.user.js` (Tampermonkey, `@match https://karte.medley.life/*`, `@updateURL`/`@downloadURL` on raw.githubusercontent main). Bump `@version` on every change.
- `clinics-tools.user.js` is the bundle users install; it is generated by `build.py` and rebuilt by `.github/workflows/build.yml` on push to main. Never edit it by hand; run `python3 build.py` locally too if you want it in the same commit.
- Add a new tool by adding a new `*.user.js` and a README section. Code runs only in the browser and must not send data anywhere.
